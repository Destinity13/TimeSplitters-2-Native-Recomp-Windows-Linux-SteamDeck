# Version 1.2.1 - better updates

16 November 2026

A small update for the launcher. The game itself is the same as in 1.2.

## What's new

* When a new version is out, the launcher tells you right at the start in a pop-up. You decide: update now, play your current version first, or later.
* The play button turns green and shows the new version, so you can still pick either way.
* While updating you see every step: backing up your saves, downloading (with size, speed and time left), checking every file and installing.
* At the end the launcher tells you it's done and you can start right away.
* The game only gets linked again when an update really changes the game code. Updates like this one start in seconds.

## Install

On Windows and Linux the launcher installs 1.2.1 by itself. This time it still works the old way, from the next update on you get the new pop-up.

Thanks to everyone who keeps reporting bugs and sending screenshots. And to Lowkas, who will still click "Later" on every update pop-up and then ask why his game is old.
