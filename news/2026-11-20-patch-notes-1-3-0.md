# Crystal Cut 1.3.0 - patch notes

The biggest update since the port came out. This is everything that is new since 1.2.1.

The port has a new name: **Crystal Cut**. In TimeSplitters 2 everything revolves around the time crystals, and this edition is about the cut: content the developers cut before release that is still sitting on the original disc. We went through the whole disc, file by file and table by table, and brought back what could be brought back.

**Everything restored comes from your own game disc.** Nothing from the game is in the download, and nothing was taken from other games or leaked builds. Every restored piece is on by default and has its own switch, so you can still play the game exactly like on the PS2.

You need your own copy of the game, USA or PAL.

## The numbers

- 1.2.1 to 1.3.0: more than 140 USA builds and 39 PAL builds, more than 400 test runs
- 2 discs supported instead of 1
- 128 MB of game memory instead of 32 MB
- 9 more Arcade maps in the map list
- 25 more characters, plus the Consultant
- 4 cut characters back in the story
- 1 new way to play: MapMaker Story in co-op
- 8849 files in 88 archives on the disc checked one by one

## Firsts

As far as we know, none of this has been done before on TimeSplitters 2. We checked The Cutting Room Floor, the TimeSplitters wiki, Nexus and ModDB before calling anything new. If someone did it first, tell us and we will happily give credit.

- **MapMaker Story co-op on the PS2 version.** The GameCube version can do it with mods. On PS2 it never worked, and the Vanilla+ PS2 page says the lock could not be found. We found where the game forces MapMaker maps to one player and where player 2 gets a start position in the void. Now a second player joins in split screen with shared objectives. Works on all three story sample maps (Porridge Bust, Zombie Lab, Splitter Base), USA and PAL. Just plug in a second controller.
- **Cut characters as story enemies.** Lean Molly and Ample Sally are loaded in Wild West but never placed. Marco the Snitch and the Reaper Splitter are loaded in Notre Dame but never placed. Now all four are part of the enemy groups in their levels.
- **Chicago, Atom Smasher and NeoTokyo as Arcade maps.** Their arcade setups are on the disc but the map list never showed them. Chicago had no spawn points in Arcade, so it gets 19 from its own story setup.
- **Spacestation and Robot Factory as Arcade maps.** Both have arcade setups but run out of memory while loading on a real PS2. With 128 MB they load and play.
- **Planet X as an Arcade deathmatch map.** Its arcade setup only allowed a Story mode that was cut. It now allows deathmatch.
- **128 MB game memory in a PS2 recompilation of this game.** The game heap is moved above the original 32 MB and is about four times as big. Same speed as before.
- **One on One is playable in TimeSplitters 2.** A complete mode entry with name, description and icon that the menu always skipped.
- **25 characters added on top of the roster.** Mods replace existing characters to make room. We moved the character list and extended it, so nobody is lost.
- **Louie Bignose speaks with his own voice.** Nine recordings made for him sit on the disc unused. In the released game he borrows another character's voice.
- **PAL and USA are one game.** Both discs play the same port at 60 Hz, start in English, share save files and play online together.

## PAL support: one port for both discs

1.2.1 only knew the USA disc. 1.3.0 takes the European disc too, and both play the same game.

- The European disc (SLES-50877) was recompiled from scratch and brought to the same state as the USA version
- One download for both discs. The setup checks which disc you have and builds the right game
- PAL runs at 60 Hz instead of 50 Hz. For that, 723 timing values in the PAL game were set to the USA timing (226 instructions, 479 float constants and 18 more for the HUD timer), so speed, timers and animations match
- Both versions start in English. PAL owners can pick the game language in the launcher (English, French, German, Spanish, Italian)
- Shared saves: a profile saved with one disc loads with the other
- Cross-region online: USA host with PAL guest and the other way round, tested in full matches
- All restored content works on PAL: 137 of 137 data fixes, characters, maps, modes, co-op, story enemies
- HD texture packs made for the USA version work on PAL
- Online+ kill feed and scoreboard show the right names on PAL
- Every build is tested on both discs with the same test cases

## 128 MB memory

- The game now gets 128 MB instead of the 32 MB of a real PS2
- The game heap moved above 32 MB and grew to about four times its size
- This is what lets Spacestation and Robot Factory load as Arcade maps
- The MapMaker gets four times the room for the level it builds
- Four places in the runtime treated every address above 32 MB as broken (DMA tags, VIF downloads, file loads, RPC sizes). All fixed
- Same frame rate as before, checked on every test case for both discs
- The old 32 MB layout is still there as a switch

## MapMaker

- **Story co-op** (see Firsts)
- **Tile budget:** the original limit of 3500 units is doubled, and with 128 MB the game has four times the memory to build the map
- **Gothic tile set** unlocked. It was shown in the official strategy guide and cut late, its files are on the disc
- **Enemy spawn limit** as a setting. The original allows 10 spawn points, you can raise it up to 1000
- **Invisible walls fixed (#14):** maps showed no walls in the preview while collision worked. One CPU instruction was translated wrong
- All seven sample maps load and play, including the three story maps
- Works the same on USA and PAL

## Restored content

- **Consultant** in the character select
- **25 extra characters:** Barrel Robot, Portal Daemon, X-Ray Skel, Gasmask Special, John Vattic and 20 NeoTokyo civilians
- **John Vattic** from Second Sight. His model is hidden in the character files under another character's name
- **Arcade maps:** Dam, Wild West, Notre Dame, Chicago, Atom Smasher, NeoTokyo, Spacestation, Robot Factory, Planet X
- **Weapons:** Desert Eagle, Mox and Silenced Luger with their names in the custom weapon set
- **Desert Eagle no longer white.** Six Arcade levels do not carry its texture. The port now adds the missing file from another archive on your disc while the level loads
- **Desert Eagle aim view** fixed, it has its own weapon entry that the aim fix did not cover
- **Barrel Robot** has his own name instead of a weapon name
- **One on One** in the mode menu
- **Thief with teams**
- **Dam and Wild West in Flame Tag and Virus**
- **Extended Easy Mode** as an option
- **Skating cheat** unlocked
- **Louie Bignose's own voice** (switchable)
- **Story enemy limit** as a setting. We found the three places that limit how many enemies are active at once (6 to 8 per level, hard stop at 20). Default is the original value
- **137 data fixes** applied at start, on both discs
- Levels without an Arcade archive load from their story archive

## What we found on the disc

Not everything can be played, but all of it is real and still on the disc. Most of this is not documented anywhere we could find.

- **A voice actor's demo recording.** Four clips of a speaker showing his range, shipped by accident and never used
- **Leftovers from TimeSplitters 1** in the sound bank: sounds for the Bank, the Mall, Cyberden and Planet X, and pickup sounds for items that do not exist in TS2
- **Four complete voice sets without a character:** Female Cop, Lumberjack, Mummy and Stewardess, all characters from the first game
- **49 muted sounds.** Entries that point to silence, including guard alerts, a safe explosion and the UFO flyby of Planet X
- **An unused ambient track** (crickets, 104 seconds) and two silent placeholder tracks among the 81 music tracks
- **121 files the game asks for that are not on the disc.** Among them 12 skies (Mars, Rainbow, Purple Haze, Asylum and more), Wild West interiors, objects for Robot Factory, Spacestation, NeoTokyo and Notre Dame, a fruit grenade and an old crosshair
- **A cut Arcade Story mode.** The mode table has a Story entry for Arcade and Planet X has a setup for it. Menu, options and character select work. The level data it needs is not on the disc, so it cannot be finished. This is very likely the cut map "Martian"
- **The British text set on the USA disc.** All 5113 texts exist twice, the only difference is the spelling
- **A placeholder level** (106) with empty data
- **The game's hidden limits:** story enemy limits per level, MapMaker place limits for 26 item groups, the 20 slot Arcade map list, the 127 slot character list
- **The mode table has 21 entries,** not 16. Assault lives there too and is only allowed in the league
- **The attract demos** still play in the port if you leave the title screen alone
- Sony's network setup program and a trailer for another game are on the disc too
- Nothing is hidden between files: every gap in all 88 archives was checked

## New menu and settings

- **Crystal Cut tab** in the game menu (F1) with a switch for every restored piece
- **Presets:** everything on, original PS2, Steam Deck 60 fps and more
- **Profiles:** save your settings under a name, load, overwrite and delete them
- **The launcher has the same options** and the same profiles as the game menu
- **Menu key:** ESC no longer opens the menu, so it is free as a back key. F1, Guide and Select+Start always work. An extra key can be picked (ESC, F2, F3, F4 or ^)
- **Low stimulus options:** hit tint, health arc opacity and soft camera cuts, each with its own slider. Made after a request from a player
- **Field of view slider** that really works now
- **Launcher:** PAL support, region in the status bar, game language for PAL, low stimulus sliders, Crystal Cut tab

## Fixes

- MapMaker walls invisible in the preview (#14)
- Difficulty select highlight did not cover the box in widescreen (#15)
- Text stretched and letters overlapped in widescreen pause menus (#16)
- Turret did not work the second time you used it (#18)

- Field of view slider had no effect, then moved the weapon and shifted enemies at high values
- Scope crosshair fix
- Alarm and camera lights off centre in widescreen and ultrawide
- Rumble motors swapped, pulses too short to feel
- The game opened on a random monitor and stretched on portrait screens. It now opens where your mouse is
- Settings menu cut off on ultrawide screens
- Character select crashed on a character whose model is missing on the disc
- Extended Easy Mode switch did nothing in test builds
- Both versions start in English instead of guessing from the system language
- Window icon on Linux
- Weapon switching with number keys removed again, it broke the original controls
- Rare picture corruption under heavy load checked again: all long test runs on the current build clean
