# Crystal Cut 1.3.3 patch notes

Aiming, controls and a setup that runs on a lot more PCs. Just start the launcher and press Update. Your saves and settings are kept, and the game is set up once more automatically with the disc you used before (a few minutes). Fresh installs can grab the full package from the [release page](https://github.com/Destinity13/TimeSplitters-2-Native-Recomp-Windows-Linux-SteamDeck/releases/tag/v1.3.3).

## Aiming and controls

- **Hip fire hits where the crosshair is** (#25, #9). Thanks to parabolee for sticking with this one!
- **Sniper scopes pan at the edge of the screen again, and shots land on the crosshair** (#21). Both had the same cause. Thanks to MikerMoo!
- **Scopes on a controller are no longer far too twitchy** (#13, #30). Zoomed in, the turn speed follows the zoom on a gamepad too. Thanks to SamuelDowse and fpen3!
- **Auto aim with modern controls on gamepad** (#27). Thanks to jobjohn26-byte for the request!
- **Picking up the controller now always wins over the mouse.** If the mouse was captured, any gamepad input releases it right away, so you never end up stuck in the slow mouse aim mode while playing with a controller. On the Steam Deck the trackpad and the buttons still work together.
- **Mouse and gamepad at the same time** (#20). If you really want both, turn on the new option "Mouse and gamepad together" under mouse aiming.
- **Turrets work from awkward angles** (#24). You don't have to line up the crosshair first anymore.

## Worth knowing: options you may have missed

All of these are off by default, so the game plays like on the PS2. Turn them on in the settings (F1 in the game or the launcher):

- **Modern aiming** on the gamepad: the right stick turns the view, the crosshair stays in the centre, L2 zooms
- **Auto aim** with modern aiming or the mouse, if you want the game's aim help back
- **Mouse aiming** with raw mouse input, like a PC shooter

## Visuals

- **No more screen shake on Siberia** (#31). The port mistook some stairs for a turret. Thanks to meddy!
- **Fire effects line up in widescreen again** (#28), and the team icons above heads in Team Deathmatch should too. Thanks to SamuelDowse!
- **HUD fixes for 21:9, 16:10 and 32:9.**
- **No more bouncing while turning with V-Sync on.** The game now follows the refresh rate of your monitor when it is close to 60 Hz, like PCSX2's "Sync to host refresh rate".
- **Smoother frame pacing with V-Sync off.**
- **Pause menu text no longer stretches** (#16). Thanks to SusDTSteve! The NeoTokyo terminal screens are still on the list.

## Setup on more PCs

- **"VU1 decoding produced nothing" is fixed** (#26). The setup no longer has to start the game for that step, a small tool reads the VU1 programs straight from your disc. Thanks to MusicGoat91 for the report and the patience!
- **SSE4.1 is enough now.** The prebuilt parts no longer need AVX2. AVX and AVX2 are still used on CPUs that have them.
- **A clear message if a CPU really is too old,** instead of a cryptic error.
- **The setup adapts to your free RAM.** It runs only as many build jobs at once as fit into memory, so PCs with little RAM don't choke anymore.
- **Better performance on weaker PCs.**

## Arcade and challenges

- **Bots no longer spawn on top of each other** on the extra arcade maps (Chicago, Atom Smasher, NeoTokyo, Spacestation, Planet X, Robot Factory). They now use the spawn points of the story levels too.
- **The glass challenge timer no longer counts too much** when the frame rate drops.

## Tested before release

- Collective test on USA and PAL (story, sniper scope, deathmatch with bots, menus, Online+ browser and bot match), all passed
- Fresh install of exactly these packages and the update from 1.3.2 the way the launcher does it on Linux, saves kept
- Fresh install and update on a weak Windows laptop with the release candidate

## Known issues

- The field of view slider is held back in this version. At higher values some effects and shadows were drawn in the wrong place, so the game stays at the original 60 until that is fixed properly.
- In 16:9 the water spray of the fountain on Mexican Mission sits a bit off. It is the same kind of widescreen spot as the lamp glows were, and it is next on the list.
